# Hair — référence du résultat d’analyse

Image : `hair-result-reference-v2.png`. Générée avec l’outil d’images intégré à partir de `hair-layout-reference-v1.png`, utilisée uniquement comme référence de style. Le générateur d’images ne propose pas de sélection de modèle Astra ; l’image n’est donc pas attribuée à ce modèle.

## Prompt envoyé

Use case: ui-mockup. Design ONE beautiful production-ready iPhone 16 screen for Beautify: the Hair recommendations result. The attached reference is ONLY for Beautify's existing style: warm blush/ivory, chocolate typography, delicate copper, pearlescent glass, bottom navigation Accueil / Analyses / Profil. Focus solely on this page and invent an exceptionally harmonious layout. Do not simply repeat the cramped second screen in the reference.

Required contents: back control; heading "Les coupes faites pour vous."; three very compact personal attributes "Ovale", "Ondulés", "Mouvement souple"; three hair recommendations using the same brunette woman with clearly different haircuts: "Lob souple", "Dégradé cascade", "Carré net". Each has a meaningful large hairstyle photo, name, and one short reason. Best recommendation is clearly distinguished. Secondary links "Voir les autres coupes" and "Comprendre mon analyse". Entire recommendation cards are tappable. No History or New analysis buttons, no scores, no quota, no report tabs, no paywall.

Let the designer choose composition, typography hierarchy, cropping, spacing, and card structure to make this exceptionally cohesive and calm. Important: hairstyles should be large and comparable, not tiny women at the bottom of big blank boxes; minimal nested glass containers; no giant panel wrapping every card. French text readable at real mobile scale. Existing sans-serif typography, refined medium-bold headings. Keep the three global bottom navigation items unchanged.

Deliver a single straight-on full-screen UI, aspect 393:852, no device frame, no presentation board, no surrounding margins. This is a layout reference to be implemented in working HTML/CSS. Beautiful but realistic.

## Transposition dans l’application

Trois cartes horizontales, avec les vrais portraits du catalogue, une brève explication visible pour chacune et une bordure cuivrée pour la première. Suppression du panneau extérieur et des numéros de recommandation. Navigation globale et autres écrans conservés. Les chevrons du mockup ne sont pas repris : chaque carte entière ouvre sa coupe.
