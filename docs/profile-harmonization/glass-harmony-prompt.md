# Référence commune de verre

Générée avec le générateur d’images intégré à partir du bouton fourni par l’utilisateur. La planche guide les matériaux ; elle n’est pas utilisée comme image d’interface.

## Prompt

Use case: ui-mockup. Create one high-definition visual material reference board for an existing premium beauty mobile application, Beautify. Input image is the user's strict style reference for the SMALL PRIMARY ACTION BUTTON, not a layout to enlarge into every component. Match its warm peach translucent glass, warm brown text, white luminous curved bevel, peach inner rim, four delicate end highlights and soft warm cast shadow.

Show exactly three component examples stacked with generous space on the same pale blush background, all in one cohesive material family:
1. A small horizontal rounded capsule button labelled exactly "Créer un compte", matching the input image's convex glass and approximately 5:1 proportions.
2. A much wider navigation card labelled "Photos et données", subtitle "Gérer mes fichiers", a small copper photo outline icon on left, a small simple brown chevron on right. This card is a thin flat sheet of lightly frosted peach glass, rounded rectangle, subtle fine white edge, very soft shadow, transparent center; NOT a swollen giant pill and NOT four brilliant button corner spots.
3. A thin flat shared glass panel containing three tidy navigation rows: "Ma photo ne s’importe pas", "Mon analyse ne s’affiche pas", "Mon accès Plus n’est pas reconnu". Tiny consistent copper outline icons left, simple chevrons right, fine separators. Rows are flush with the panel; do not frame them as three separate shiny buttons.

Lighting and palette must exactly harmonize with the provided button. Typography crisp dark warm brown sans serif. High craft, restrained luxury. Front-facing orthographic UI, no device frame, no perspective, no extra decoration or explanatory labels, no invented functionality. This is a visual design reference only; actual application text and interactions will remain native HTML.
