# Verre atténué

Référence générée avec l’outil intégré à partir du bouton fourni par l’utilisateur. Le nouveau choix privilégie l’harmonie de la page entière et remplace l’ancienne capsule très bombée.

## Prompt exact

Use case: ui-mockup. Generate a refined visual material reference for the existing Beautify mobile profile UI. Input image is the user's previous glass-button style reference; preserve its warm blush/peach palette and translucent quality but deliberately reduce its inflated bevel, four hotspot reflections and heavy shadow by about 80%. User now finds this glass excessive and wants quiet, harmonious glass integrated with the rest of the application.

Front-facing portrait board on a pale peach cloudy background, three samples:
Top: a rounded translucent panel with title "Mon compte", two understated flat input fields "Adresse e-mail" and "Mot de passe", and one action button "Se connecter". The primary button has a delicate peach tint, fine white top rim, very shallow curved surface, restrained warm shadow and crisp warm brown text. NO bright corner glints, NO thick white double ring, NO metallic or candy-like inflated pill.
Middle: a secondary action "Continuer avec Apple" and below it a simple unframed text link "Mot de passe oublié ?". Secondary action uses the same quiet glass surface as the panel, less emphasis than primary.
Bottom: a flat translucent navigation card "Photos et données" with subtitle "Gérer mes fichiers", small warm brown photo outline icon left, simple chevron right. Same material/lighting/palette as top panel.
Premium means consistent proportion, quiet light and clear hierarchy, not more reflections. Keep the glass discernible through soft translucency and a thin edge. High definition, clean typography, no device frame, no extra labels or decorative objects. This reference guides native CSS components, never rasterized UI text.
